# DON & SONS POS - FIELD INSTALLER QUICK REFERENCE

**Print this card and keep it with you during installation**

---

## ⚡ SUPER QUICK STEPS (30 minutes)

1. **Copy installer** from USB to Desktop
2. **Run installer** (double-click, click Yes, click Next/Finish)
3. **Login** (email + password)
4. **Select outlet** (top-right corner, click dropdown, choose CORRECT outlet)
5. **Wait** for products to load (1-2 min)
6. **Test online** (make a sale, verify it syncs)
7. **Test offline** (disconnect internet, make a sale, reconnect, verify sync)
8. **Train staff** (5 min demo)
9. **Done!** Fill report and leave

## ✅ MUST TEST BEFORE LEAVING

### Online Test:
1. Add 2 products
2. Click PAY
3. Select Cash
4. Complete sale
5. ✓ Should show "Synced"

### Offline Test:
1. Disconnect WiFi
2. Make a sale
3. ✓ Should show "Pending"
4. Reconnect WiFi
5. Wait 10 sec
6. ✓ Should change to "Synced"

**If offline doesn't work → CALL SUPPORT → DON'T LEAVE!**

---

## 🚨 COMMON PROBLEMS

### "Cannot reach server"
- Check internet (open browser, visit google.com)
- Reconnect WiFi

### "Login failed"
- Turn OFF Caps Lock
- Type password carefully
- Check credentials

### "No products"
- Wait 2 more minutes
- Check internet
- Logout & login again

### Installer won't run
- Right-click → "Run as administrator"

### Products not loading
- Internet not working
- Wait 3 minutes
- If still empty → call support
